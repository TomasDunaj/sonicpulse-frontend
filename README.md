## 📖 About the Project

SonicPulse Frontend is the client-side web application designed to give users an intuitive and immersive way to interact with the AI playlist generator. 

The interface allows users to input prompts, explore curated tracks, view album covers, and listen to audio previews in a clean, modern dark-themed environment. Special attention was paid to responsive design, robust text-wrapping safeguards for long track titles, and dynamic typography to ensure a flawless experience across mobile and desktop devices.

This project was built to master frontend state management, component architecture, and responsive CSS layout design while integrating seamlessly with a custom Spring Boot backend.

---

## ✨ Features

- **🎨 Modern Dark UI**
  - Clean, music-focused aesthetic designed for optimal user experience.
- **📱 Fully Responsive Design**
  - Fluid layouts and dynamic font sizing (`clamp()`) tailored for both desktop and mobile screens.
- **🔄 Seamless API Communication**
  - Instantly communicates with the backend to handle playlist generation requests and media playback data.

---

## 🛠️ Tech Stack

- **⚛️ React & Vite**
  - Used for building reactive UI components, managing application state, and ensuring fast bundling.
- **🎨 Modern CSS3**
  - Leverages Flexbox, CSS Custom Properties, and dynamic typography scaling for layout perfection.
- **🔌 REST API Integration**
  - Connects securely with the Spring Boot backend to fetch and display dynamic music data.
